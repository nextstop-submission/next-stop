## 만드는 경로 (위가 먼저, 지출 0)

1. **에뮬레이터 녹화** — 노트북이 되면 `scripts/demo/demo.ps1 -Launch -Stops 5 -Record`(Virtual Console 창을 같이 찍으려면 Windows 기본 화면 녹화 Win+Alt+R). 노트북이 안 되면 GitHub Actions `emulator` 워크플로가 Virtual Console을 눌러 녹화한 mp4(`docs/probe-results/ci-*/vc-drive-clean.mp4`, 브랜치에 자동 커밋)를 쓴다. 창 없는 소프트웨어 렌더링이라 Virtual Console 화면 자체는 녹화에 없지만, 왼쪽 Pleos 차량 패널에 문 열림·기어가 그대로 보인다.
2. **화면 테스트 렌더링** — 에뮬레이터 녹화가 둘 다 실패하면 Robolectric 화면 테스트가 그린 장면(`docs/screens/`)을 이어 붙인다. 자막에 '앱 화면 렌더링(에뮬레이터 아님)'을 밝힌다.
3. **편집** — 자막·카드 합치기는 무료 도구(ffmpeg 또는 Windows 기본 Clipchamp 무료 기능)로. 유료 템플릿·음원 쓰지 않는다. 음악을 넣으면 저작권 걱정 없는 것만(없어도 됨).

## 익명 점검

- 화면에 계정·알림·사용자 이름·바탕화면이 나오지 않게 에뮬레이터 창만 찍는다.
- 파일 메타데이터(제목·작성자)를 비우고 올린다(`/aiclean` 또는 ffmpeg `-map_metadata -1`).
- 올릴 곳: 익명 제출 저장소 README의 링크(파일 크기가 크면 저장소 Release 첨부) — 개인 유튜브 계정은 쓰지 않는다.
