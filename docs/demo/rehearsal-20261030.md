## 대본에 반영한 것 (`docs/demo/demo-script.md`)

1. 리허설 체크리스트: Cold boot 뒤 내비가 스스로 뜨니 지도 로딩이 끝난 뒤 앱을 연다.
2. 0:40: 내비가 앞으로 나오면 앱으로 돌아오는 손동작을 넣는다(리허설에서는 처음에만 생김).
3. 2:00~2:20: 남은 건은 말하면서 빠르게 P·문·문·D(최소 정차 시간 없음). 5건을 다 해야 정산이 뜬다.
4. 2:20: 시연 정산은 운행이 몇 분이라 시간당 실수익이 비현실적으로 컸다 → **제품에서 고침**: 운행 30분 미만이면 시간당 값을 내지 않고 순수익과 '30분 이상 운행하면 표시' 안내를 보인다(`core` `Settlement.MIN_MINUTES_FOR_HOURLY`, 단위 테스트).
